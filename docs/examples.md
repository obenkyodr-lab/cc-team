# 使い方の例

各業務について「ユーザー入力 → AIの動作 → 保存先」の流れで説明する。

---

## TODO整理

**ユーザー入力:**
```
今日やることを整理して。外来12時まで、13時から手術が1件、17時にカンファ。夜までにA氏へメールの返信。
```

**AIの動作:**
- 入力から業務スケジュールと隙間時間を把握する
- 既存の未完了TODOと組み合わせて優先順位を整理する
- 今日の日付でTODOファイルを作成（または追記）する

**保存先:** `secretary/todos/YYYY-MM-DD.md`

---

## 会議議事録

**ユーザー入力:**
```
カンファの議事録を作って。

決定事項：
- A患者の術式をLAに変更
- B患者は来週再評価

TODO：
- 佐藤が紹介状を作成（期限：今週金曜）
- 田中がCT予約（期限：明日中）
```

**AIの動作:**
- 決定事項・TODO・参加者を構造化された議事録フォーマットに整理する
- 日付・会議名でファイルを作成する

**保存先:** `operations/minutes/YYYY-MM-DD-カンファ.md`

---

## メール返信

**ユーザー入力:**
```
製薬会社の担当者から来週の打ち合わせ日程の確認メールが来てた。
水曜14時以降か木曜午前なら空いてる。
```

**AIの動作:**
- 状況を踏まえた返信文を作成する（件名・本文・署名）
- Gmail下書きに保存する（Gmail連携済みの場合）

**保存先:** `operations/mail/YYYY-MM-DD-打ち合わせ日程.md`（＋Gmail下書き）

---

## 学会抄録

**ユーザー入力:**
```
乳癌学会の抄録を書いて。600字以内。

研究：当院でT-DXdを投与したHER2低発現乳癌46例の後ろ向き解析。
結果：ORR 52%、mPFS 8.3ヶ月。IHC 2+でより高い奏効率。
```

**AIの動作:**
- 背景・目的・対象と方法・結果・結論の構成で抄録を作成する
- 文字数をカウントして制限内に収める
- 不明な数値・エビデンスは「要確認」とマークする

**保存先:** `agents/abstract/YYYY-MM-DD-乳癌学会.md`

---

## スライド準備

**ユーザー入力:**
```
来週の抄読会のスライドを作って。
論文：DESTINY-Breast04のNEJM論文。発表15分、スライド12枚くらい。
```

**AIの動作:**
- 論文の要点（背景・デザイン・結果・考察・臨床的意義）をスライド構成に落とし込む
- 各スライドのタイトル・要点・メッセージを整理する
- 発表時間に合わせた構成を提案する

**保存先:** `agents/slide/YYYY-MM-DD-抄読会DESTINY-Breast04.md`

---

## 論文要約

**ユーザー入力:**
```
この論文を要約して（PDFを添付）
```

**AIの動作:**
- 背景・研究デザイン・主要エンドポイント・結果・限界・臨床的意義を構造化して要約する
- 統計値・エビデンスは原文から正確に引用する（推測・補完しない）

**保存先:** `projects/[論文名]/summary.md`
