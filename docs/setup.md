# セットアップ詳細

## 前提条件

- [Claude Code](https://claude.ai/code) がインストール済みであること

---

## インストール手順

### マーケットプレイスとして登録する（推奨）

Claude Code で以下の2コマンドを実行する:

```
/plugin marketplace add obenkyodr-lab/cc-team
/plugin install team@cc-team
```

GitHubのリポジトリURL（`https://github.com/obenkyodr-lab/cc-team`）を伝えて「プラグインインストールして」と言うだけでも、Claude Codeが上記と同じコマンドを実行してくれる。

チーム全体に自動配布したい場合は、`~/.claude/settings.json`（または `.claude/settings.json`）に以下を追加する:

```json
{
  "extraKnownMarketplaces": {
    "cc-team": {
      "source": {
        "source": "github",
        "repo": "obenkyodr-lab/cc-team"
      }
    }
  },
  "enabledPlugins": {
    "team@cc-team": true
  }
}
```

Claude Code を再起動すると `/team` が使えるようになる。

### ローカルで直接使う場合

リポジトリをクローンし、`skills/team/SKILL.md` を参照する。

---

## 初回セットアップ（オンボーディング）

プロジェクトフォルダで `/team` を実行すると、2問の質問が表示される。

**Q1: チームの種類**
- 診療チーム（外科・内科など）
- 臨床研究チーム
- 学術・教育チーム
- その他

**Q2: よく行う業務（複数選択可）**
- 日常業務（メール、議事録）→ `operations/minutes/`、`operations/mail/` を追加
- 学会発表（抄録、スライド）→ `agents/abstract/`、`agents/slide/` を追加
- 研究（臨床研究・論文作成など）→ 上記に加えて研究パイプラインエージェントの追加を提案

回答後、`.team/` フォルダと `.claude/settings.json` が自動生成される。

---

## 起動の自動化（オプション）

毎回 `/team` を手入力するのが面倒な場合は、秘書に「起動を自動化して」と伝えると `.vscode/tasks.json` が生成され、VS Code でプロジェクトを開くだけで Claude Code が自動起動するようになる。

> **注意**: VS Code で「タスクを自動実行してよいか」の確認ダイアログが出た場合は「許可」を選択すること。

---

## 後から業務を追加する

運用を始めてから「PM部署を追加して」「データ解析エージェントを追加して」と秘書に話しかけると、対応するフォルダと設定ファイルが追加される。

追加できる業務・エージェントの一覧:

| 種別 | 名前 | 主な用途 |
|---|---|---|
| 部署 | PM | プロジェクト進捗・締め切り管理 |
| 部署 | 経理 | 請求書・経費・売上管理 |
| エージェント | 情報収集 | 文献検索・情報整理 |
| エージェント | 論文要約・解釈 | 論文の構造化要約と意義の解釈 |
| エージェント | 研究デザイン | PICO整理・デザイン選択・バイアス評価 |
| エージェント | データ解析 | データクリーニング・統計解析支援 |
| エージェント | 論文執筆 | 各セクション草稿・投稿規定への整形 |
| エージェント | 論文査読 | 査読コメント対応・改訂整理 |
