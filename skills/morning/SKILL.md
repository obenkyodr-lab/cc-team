# /morning — モーニングルーティン

## いつ使うか

- `/morning` を実行したとき
- 「おはよう」「おはようございます」「morning」「Good morning」など朝の挨拶を受けたとき

---

## 前提確認

最初に `.team/` フォルダが存在するか確認する。

- **存在する** → 以下のステップを順番に実行する
- **存在しない** → 「先に `/team` を実行してセットアップを完了してください」と伝えて終了する

---

## 実行手順（確認不要・即座に実行）

### Step 1: 日付確認

`date` コマンドで今日の日付・曜日を取得する。以降のステップで使用する。

### Step 2: 今日のTODO

`.team/secretary/todos/YYYY-MM-DD.md` を読み込む。

- **ファイルが存在する** → 未完了タスク（`- [ ]`）を一覧表示する
- **ファイルが存在しない** → テンプレートで新規作成し「今日のTODOはまだありません」と表示する

新規作成テンプレート:

```markdown
---
date: "YYYY-MM-DD"
type: daily
---

# YYYY-MM-DD（曜日）

## 最優先
- [ ]

## 通常
- [ ]

## 完了
```

### Step 3: メールチェック（Gmail連携済みの場合のみ）

Gmail MCP が利用可能な場合のみ実行する。利用できない場合はこのステップを**スキップ**して Step 4 へ進む。

未読メールを最大20件取得し、以下の基準で分類・表示する:

| 分類 | 基準 | 対応 |
|------|------|------|
| 🔴 **要返信** | 個人・企業からの直接メッセージで返信が必要 | 表示 + TODO追加 |
| 🟡 **要対応** | 返信以外のアクションが必要（書類・フォーム・期限付き手続き） | 表示 + TODO追加 |
| 🟢 **情報把握** | 学会案内・論文通知・お知らせなど | 件数のみ表示 |
| ⚪ **不要** | ニュースレター・営業メールなど | 報告しない |

**注意事項:**
- CC・BCC メールは返信不要なことが多い。全体配信・お知らせ系は 🟢 または ⚪ 扱いとし、個人への返信が本当に必要か慎重に判断する
- 🔴🟡 の件名・送信者を一覧表示する。🟢 は「N件（省略）」とまとめてよい

### Step 4: 今日の予定（Google Calendar連携済みの場合のみ）

Google Calendar MCP が利用可能な場合のみ実行する。利用できない場合はこのステップを**スキップ**して Step 5 へ進む。

今日の予定を時刻順に一覧表示する（時刻・タイトル）。予定がない場合は「今日の予定はありません」と表示する。

### Step 5: 今日の一言

1日を前向きに始められる短いひと言を生成する。ユーザーの言語を自動検出し同じ言語で出力する。

---

## 出力フォーマット

```
# おはようございます！ YYYY年M月D日（曜日）

## 📋 今日のTODO
- [ ] タスク...
（未完了タスクがない場合: 「今日のTODOはまだありません」）

## 📧 メール（※Gmail連携済みの場合）
🔴 要返信 (n件)
- 件名 — 送信者
🟡 要対応 (n件)
- 件名 — 送信者
🟢 情報把握 n件（省略）

## 📅 今日の予定（※Calendar連携済みの場合）
- HH:MM 予定名
- HH:MM 予定名

---
💬 今日の一言: ...
```

---

## 連携ツールが未設定の場合の案内

Gmail・Google Calendar が未連携でメール・予定セクションをスキップした場合、末尾に以下を一度だけ表示する:

> 📌 Gmail・Google Calendar を連携するとメール確認・予定表示もまとめて確認できます。
> 連携方法は `/team` → 「Gmail連携したい」「カレンダー連携したい」と話しかけてください。

---

## TODO への自動追記ルール

Step 3 で 🔴 または 🟡 のメールを検出した場合、以下の形式で `.team/secretary/todos/YYYY-MM-DD.md` に自動追記する:

```markdown
- [ ] 返信: [件名]（[送信者]）| 優先度: 高 | 期限: YYYY-MM-DD
```

追記はユーザーへの確認なく自動で行う。

---

## セッションログへの記録

モーニングルーティン実行後、`.team/secretary/logs/YYYY-MM.md` に以下を追記する:

```markdown
## YYYY-MM-DD（曜日）モーニングルーティン
- TODO: N件（未完了N件）
- メール: 🔴N件 🟡N件 🟢N件（※Gmail連携済みの場合）
- 予定: N件（※Calendar連携済みの場合）
```
