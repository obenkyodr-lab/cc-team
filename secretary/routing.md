# routing.md — Secretary 振り分けルール表

---

## 目的

Secretaryが依頼内容を見て、どの担当に振り分けるかを決めるためのルールを定義する。

---

## 基本方針

1. 依頼を1〜2文で要約する
2. 以下の振り分け表に照らして分類する
3. 定型作業 → `operations/` 内のSKILL.md を使う
4. 判断・構成・戦略が必要な作業 → `agents/` 内のagent.md を使う
5. プロジェクト固有の作業 → `projects/<案件名>/pm_agent.md` を参照する
6. 迷った場合はSecretaryが暫定対応し、必要なら追加確認する

---

## 振り分け表

### 議事録作成

**対象キーワード・依頼例：**
- 会議の文字起こし・書き起こし
- Plaud などの音声テキスト（speaker1 / speaker2 形式を含む）
- 会議内容の要約
- 決定事項・ToDo の抽出

**担当：** `operations/minutes/SKILL.md`

---

### メール処理

**対象キーワード・依頼例：**
- メールの下書き・返信案作成
- 丁寧な文面への修正
- 依頼メール・お礼メール・日程調整メール

**担当：** `operations/mail/SKILL.md`

---

### 学会抄録作成

**対象キーワード・依頼例：**
- 背景・目的・方法・結果・結論の整理
- 日本語抄録・英語抄録の作成
- 文字数制限への調整
- 学会提出用タイトルの作成

**担当：** `agents/abstract/agent.md`  
構成の整理や変換のみで済む場合は `operations/abstract/SKILL.md` を直接使う。

---

### スライド構成作成

**対象キーワード・依頼例：**
- 講演・学会発表・教育講義のスライド構成
- 1枚ごとのメッセージ作成
- 発表原稿作成
- MR講演・院内講演・教育講義

**担当：** `agents/slide/agent.md`  
定型フォーマットへの当てはめのみであれば `operations/slide/SKILL.md` を直接使う。

---

### プロジェクト管理

**対象キーワード・依頼例：**
- 研究・講演・抄録・論文などの進行管理
- 次にやることの整理
- `projects/` 内のフォルダの進捗確認
- TODO 整理・スケジュール確認

**担当：** `projects/<該当プロジェクト名>/pm_agent.md`

---

### その他

**対象：**
- 既存分類に当てはまらない依頼
- 新しい業務・不明な依頼
- 新規 agent または operation が必要そうな依頼

**担当：** Secretary が暫定対応し、必要であれば新規 agent / operation の候補をユーザーに提案する。

---

## 出力形式

振り分け時に以下を明示する。

| 項目 | 内容 |
|---|---|
| 依頼内容 | 依頼の1〜2文要約 |
| 分類 | 上記カテゴリ名 |
| 使用する担当 | ファイルパス |
| 理由 | 定型 / 判断必要 / プロジェクト固有 など |
| 次に実行すること | 担当ファイルを読み込んで処理を開始する、またはユーザーへの確認事項 |

---

## 注意事項

- agent と operation を増やしすぎない。まず既存の minutes / mail / abstract / slide で対応する
- 個人情報・医療情報を含む依頼は、処理前に `shared/privacy_rules.md` を確認する
- 文体・出力形式は `shared/style_guide.md` に従う
